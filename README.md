Описание проекта:
go_final_project - это дипломный проект.
В дипломном проекте создан веб-сервер, который реализует функциональность планировщика задач - это аналог TODO-листа. 
Этот проект позволяет проверить и закрепить навыки по написанию веб-сервера, работе с REST API и базами данных.

Реализованные шаги:
1. Создание веб-сервера;
2. Проектирование и создание БД;
3. Написание функции для вычисления следующей даты у задачи.
4. Реализация обработчика для добавления задачи.
5. Получение списка ближайших задач.
6. Реализация обработчика для редактирования задачи.
7. Реализация обработчиков при выполнении задачи и её удалении.

Выполнены некоторые задания со звёздочкой, а именно:
TODO_PORT - реализована возможность определять извне порт при запуске сервера (по умолчанию: 7540)
TODO_DBFILE - реализована возможность определять путь к файлу базы данных (по умолчанию: scheduler.db)
Реализована возможность поиска задачи.

Инструкция по запуску кода локально: команда "go run main.go". 

Инструкция по запуску тестов в tests/settings.go
